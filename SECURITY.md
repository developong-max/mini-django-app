# Security Policy

## Supported Versions
Only the latest commit on `main` is actively supported.

## Reporting a Vulnerability
Please do not open a public issue for security vulnerabilities.
Instead, contact the repository owner directly and allow time
for a fix before public disclosure.

## Process
- All changes are reviewed via Pull Request before merging to `main`.
- `main` is a protected branch requiring CODEOWNERS approval.
- Dependencies should be reviewed periodically for known CVEs.
